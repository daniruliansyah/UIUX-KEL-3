## 📖 Tentang Project

**Kuecake** adalah hasil karya proyek kelompok yang kami kerjakan dengan penuh dedikasi. Proses pengembangan dimulai dari tahap perancangan UI/UX menggunakan **Figma**, hingga implementasi kode menggunakan **Native HTML & CSS**.

Poin unik dari pengembangan ini:
*   **Pure Coding:** Seluruh kode ditulis secara manual (hand-coded) tanpa bantuan AI, sebagai bagian dari proses belajar fundamental web development kami.
*   **Mobile Layout:** Saat ini, desain antarmuka dikhususkan untuk tampilan **Mobile**. Jika dibuka di layar desktop, tampilannya akan tetap menyerupai ukuran layar HP (belum *responsive* penuh).

## ✨ Fitur Utama

Kuecake hadir untuk menyelesaikan masalah ribetnya mencari bahan kue yang sesuai dengan resep. Fitur utamanya meliputi:

1.  **Explorasi Resep Kue** 🥐
    Melihat berbagai resep kue menarik (seperti Vanilla Mille Crepes, Kue Cubit, dll) lengkap dengan panduan cara membuatnya.

2.  **Bundle Bahan (Recipe-to-Cart)** 🛒
    Fitur andalan kami! Kamu bisa membeli **satu paket bahan** lengkap sesuai dengan resep yang kamu pilih. Tidak perlu mencari bahan satu per satu lagi.

3.  **Belanja A la Carte** 🛍️
    Selain bundle, pengguna juga tetap bisa membeli bahan-bahan kue satuan terpisah sesuai kebutuhan di menu "Bahan Kue".

4.  **Guest & User Mode** 👤
    Alur aplikasi yang membedakan antara pengunjung tamu (*Guest*) dan pengguna yang sudah *Login*, mencakup halaman keranjang, checkout, hingga pemberian ulasan.

## 🚀 Instalasi dan Cara Menjalankan

Karena proyek ini dibangun menggunakan HTML & CSS murni, kamu tidak perlu menginstal *dependencies* apa pun (seperti Node.js atau NPM).

1.  **Clone Repository ini**
    ```bash
    git clone https://github.com/username-kalian/github-UIUX-KEL-3.git
    ```

2.  **Buka Folder Project**
    Masuk ke direktori folder yang sudah di-clone.

3.  **Jalankan Aplikasi**
    Cari file bernama [`home(guest).html`](home(guest).html) dan buka (double click) file tersebut. File akan terbuka otomatis di browser default kamu.
